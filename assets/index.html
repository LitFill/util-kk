util-kk

A small library of utilities for the Koka language. It provides string templating, parser helpers, and effect handlers for state, reader, and exit.

Modules

Regenerating these docs

These pages come from the Koka compiler's --html backend plus the scaffolding in this repository. Rebuild them with:

nix run .#docs

The build script takes an output directory and the module list:

scripts/build-docs.sh <out-dir> <module.kk>...
