# Utilities

A small collection of general-purpose helpers used across personal projects. The contents currently fall into two groups: - Infix operators for string templating, which substitute (%)std/core/int/(%): (int, int) -> int-prefixed placeholders with replacement values. - Helpers for working with parse, including a show implementation for parse results and lexeme-style combinators.

fun lex( p : parserstd/text/parse/parser: (E, V) -> V<e,a> ) : <parsestd/text/parse/parse: (E, V) -> V|e> a
Turns a parser into a lexeme parser by discarding trailing whitespace. The parser p is run first, and any whitespace that follows it is then consumed (via whitespace0std/text/parse/whitespace0: () -> parse string) and discarded. The result of p is returned unchanged. Leading whitespace is not handled, so a grammar built from lexemes should skip any initial whitespace once, at its entry point. - p: the parser to wrap. Returns the result of p, after trailing whitespace has been consumed.

  "67   \n".slice.parse {
    with lex
    pint()
  } .println
  // ^ ParseOk(64, rest="")
